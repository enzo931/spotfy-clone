# 🎧 Spotify Minimal

Um player de música web minimalista, moderno e responsivo, desenvolvido com HTML5, CSS3 e JavaScript puro (Vanilla JS). O projeto simula a interface e a experiência de uso do Spotify, permitindo navegação entre seções, busca de faixas e controle total de reprodução de áudio.

---

## 🚀 Funcionalidades

- **Navegação Interativa**:
  - **Início**: Exibição da lista principal de álbuns.
  - **Favoritos**: Acesso rápido às músicas marcadas com estrela.
  - **Biblioteca & Playlists**: Organização de acervo pessoal e coleções de áudio.
  - **Configurações**: Painel de preferências do usuário.
- **Player de Áudio Completo**:
  - Controles de reprodução (`Tocar / Pausar`, `Anterior`, `Próxima`).
  - Sistema de **Favoritar** faixas dinamicamente.
  - **Barra de Progresso (Seekbar)** com atualização de tempo em tempo real (`0:00`).
- **Barra de Pesquisa**: Filtro em tempo real para localizar músicas rapidamente na interface.
- **Design Minimalista & Responsivo**: Interface limpa focada em usabilidade e desempenho.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias nativas do desenvolvimento web front-end, sem dependência de frameworks externos:

- **HTML5**: Estruturação semântica da aplicação (`<header>`, `<section>`, `<footer>`, `<audio>`).
- **CSS3**: Estilização da interface, layout moderno (Sidebar, Main Content e Player fixo) e temas visuais (`style.css`).
- **JavaScript (ES6+)**: Manipulação do DOM, controle do elemento `<audio>`, eventos de clique e lógica de controle de estado (`script.js`).
